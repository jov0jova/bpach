Adding Custom Indicators
How the indicator pipeline works

All indicators are computed in app/strategies/base.py inside the add_indicators(df) function. The output DataFrame columns are what you reference in entry logic and the Algo Finder.

To add a custom indicator, open app/strategies/base.py and add your pandas/ta computation. Return a new column on the DataFrame. It will automatically be available in:

  • Entry Logic conditions
  • IC Analysis (correlation with future returns)
  • Algo Finder search space
Example: Adding a custom indicator 
# In app/strategies/base.py, inside add_indicators():

# Custom: 3-bar momentum
df['MY_MOM_3'] = df['close'].pct_change(3) * 100

# Custom: EMA ratio
df['EMA_RATIO'] = df['EMA_8'] / df['EMA_50']

# Custom: volume spike flag
vol_ma = df['volume'].rolling(20).mean()
df['VOL_SPIKE'] = (df['volume'] > vol_ma * 2).astype(int)
